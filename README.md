Here's what's inside and what makes it a great intermediate-level prompt engineering project:
Core Features:

4 Tool Modes — switch between Midjourney, Runway, Sora, Kling, or generate for All at once
Smart Prompt Builder — fills in subject, art style, mood, lighting, camera angle, color palette, aspect ratio
Tag System — add custom style keywords with a chip/tag UI (press Enter)
Video-specific fields — camera motion, scene action, duration for Runway/Sora/Kling
Detail Level Slider — minimal vs. maximum prompt verbosity
Negative Prompts — tell the AI what to avoid
Artist/Director Reference — e.g. Roger Deakins, Miyazaki

Tool-Specific Prompt Logic:

Midjourney → formats with /imagine prompt: and parameters like --ar 16:9 --v 6.1 --q 2
Runway → leads with camera motion, then scene description
Sora → describes scene as a timeline (beginning → middle → end)
Kling → structured label-value format for best results

Learning Value (for your submission):

Demonstrates understanding of different prompt structures per tool
Shows parameter engineering (aspect ratios, quality flags)
Covers negative prompting, style transfer, and weighted keywords
Includes a Prompt Engineering Tips panel explaining the reasoning
